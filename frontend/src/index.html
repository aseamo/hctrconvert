Frequently Asked Questions

Is HctrConvert really free?
Yes, completely free. No sign-up, no watermarks, and no hidden limits.
Will my document formatting be preserved?
Yes. HctrConvert uses layout-preserving engines (pdf2docx, PyMuPDF, Pandoc, and LibreOffice) so fonts, headings, tables, colors, and embedded images carry over cleanly.
Are my files private?
Yes. Files are processed in isolated temporary job storage, deleted immediately after download, and swept automatically by a background cleaner.
What is the max file size?
500 MB per file by default (configurable via the MAX_FILE_SIZE_MB environment variable).
Can I convert multiple files at once?
Yes! Drop multiple files into the converter and convert the entire batch with real-time per-file progress bars.
